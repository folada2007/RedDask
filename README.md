# RedDesk

веб-приложение для учёта клиентов проектов по тестированию на проникновение (пентестов) и найденных уязвимостей

## Запуск по докер

1. 
```bash
docker compose up -d
```

2. 
```bash
go run .
```

## Запуск по постргрес
```powershell
$env:DB_PASSWORD="ваш_пароль"
go run .
```

адрес: http://localhost:5080
